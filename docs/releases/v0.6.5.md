# Collabsprite 0.6.5 Beta — eine Datei für Host und Gäste

**Download: `Collabsprite.aseprite-extension` unter Assets.** Dieselbe Datei kann eine Sitzung erstellen oder einer Sitzung beitreten. Die Host-Laufzeit für **Windows 10/11 x64** ist jetzt enthalten; Node.js muss nicht zusätzlich installiert werden. Die Diagnosefunktion gehört ab jetzt zum normalen Paket.

## Korrigiert

- **Installer als „ws 8.21.3“ erkannt:** Die Dateireihenfolge im alten Paket war falsch. Aseprite las das Manifest der Bibliothek vor dem von Collabsprite. Das Paket ist korrigiert und im echten Aseprite-Installer geprüft.
- **Update von Entwicklungsständen:** Versionsnummern wie `0.6.5-dev.1` werden akzeptiert. Downloads werden weiterhin per SHA-256 geprüft.
- **Hängende Vorbereitung:** Auch ein dauerhaft wartender Worker läuft jetzt in ein Zeitlimit. Verweigerte Dateizugriffe werden abgefangen, statt bei jedem Timer-Tick erneut zu scheitern.
- **Verschachtelte Timer-Aufrufe:** Freigabedialoge können Aseprite-Ereignisse erneut auslösen. Haupttimer und Client sind dagegen geschützt; Empfang und Diagnoseansicht führen keine Dateioperationen mehr in ihren nativen Callbacks aus.
- **Firewall beim Wechsel der Laufzeit:** Die eigenen Regeln werden auf den tatsächlichen Host-Prozess aktualisiert, weiterhin nur für LAN/Radmin und TCP/UDP 8766.

## Installieren oder aktualisieren

1. Auf allen PCs die Sitzungskopie speichern und eine laufende Sitzung trennen.
2. **`Collabsprite.aseprite-extension`** herunterladen. GitHubs **Source code (zip)** ist für Entwickler, nicht zum Installieren in Aseprite.
3. **Aseprite → Bearbeiten → Einstellungen → Erweiterungen → Erweiterung hinzufügen**, Datei auswählen und Installation/Update bestätigen. Die technische Kennung lautet weiterhin **pixelkollab-native**, der Anzeigename **Collabsprite**.
4. Aseprite neu starten. **Ansicht → Collabsprite → Info** muss **0.6.5** anzeigen.

Host: RGB-Bild öffnen → **Server erstellen / beitreten → Erstellen → Sitzung erstellen** → Einladung kopieren und privat teilen.

Gast: **Server erstellen / beitreten → Beitreten** → Einladung einfügen → Beitreten. Ein eigenes Bild braucht der Gast nicht zu öffnen.

Im selben LAN/WLAN verbindet ihr euch direkt. Über verschiedene Netzwerke zuerst demselben Radmin-VPN-Netz beitreten. Windows kann beim ersten Hosten eine Firewallfreigabe verlangen.

## Wenn noch ein Fehler auftritt

**Ansicht → Collabsprite → Diagnosekonsole → Protokoll kopieren**. Das lokale Protokoll bleibt nach einem Neustart erhalten, ist auf 512 KiB begrenzt und enthält keine Pixelbilder oder Einladungscodes. **Neues Protokoll** nur vor dem erneuten Reproduzieren anklicken. Den kopierten Text mit dem letzten Bedienungsschritt an Merthius geben.

Der konkrete „C stack overflow“ auf dem gemeldeten Freund-PC ist **noch nicht durch einen erneuten Test dort als behoben bestätigt**. Dieser Release liefert dafür die korrigierte Installation, Schutzmaßnahmen und Diagnose.
