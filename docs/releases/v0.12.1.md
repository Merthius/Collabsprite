# Collabsprite 0.12.1 Beta – flüssigere Ideenwand und korrigierter Import

**Lokal vorbereitet, noch nicht auf GitHub veröffentlicht.** Eine Installationsdatei für Host und Gäste. Alle Beteiligten brauchen dieselbe Version: **Protokoll 14 / Notizformat 9**. Vor dem ersten Speichern alter Notizen eine Dateikopie behalten.

- Ideenwand, Bildvorschauen, Skizzenkodierung und Host-Bildvorbereitung in kurzen Arbeitsschritten. Lokale Notizdaten werden vor der kurzen nativen Schreibtransaktion aufbereitet. Große native Datei-/Metadatenoperationen bleiben unteilbar und können kurz dauern.
- PNG/JPG und andere unterstützte Bilder erscheinen beim Import tatsächlich auf dem offenen Skizzenblatt. Normale RGB-Quellen benötigen keinen temporären Bildtab; indizierte Paletten bleiben nach dessen Schließen erhalten. Auch Vorlagenziehen und fremde Blattaktualisierungen werden vorbereitet statt vollständig im Klick ausgeführt.
- **Häkchen** statt X: Skizze als vollauflösendes 1000 × 1000-Bild in der Wand übernehmen. Zum Weiterzeichnen auf ein neues Blatt ziehen. Schließen der Ansicht übernimmt Änderungen automatisch; Aseprites Speichern/Schließen wartet auf die Bestätigung und geht anschließend weiter.
- Eigene Konfliktentwürfe werden bei fremder Änderung/Löschung nicht verworfen, sondern gegebenenfalls als separates Bild übernommen. Wiederholte fehlgeschlagene automatische Schreibversuche erzeugen keine Dauerschleife; der Entwurf bleibt erhalten.
- Sitzungssuche liefert ihre Ergebnisse auch aus dem Hintergrundstarter korrekt. Genau eine Sitzung wird automatisch geöffnet; mehrere bleiben auswählbar. **Trennen** erscheint nur verbunden, **Abbrechen** während Suche/Vorbereitung. Abbruch und verweigerte Verbindung lassen keine falsche Verbindung zurück.

Das Übernehmen einer Skizze ist keine separate PNG-Dateispeicherung. Der **Host speichert die Sitzungskopie als `.aseprite`**, damit Bild und Wand gemeinsam erhalten bleiben. Netzwerk-/Windows-Freigaben werden nicht umgangen. Ein Rechner ersetzt keinen Praxistest mit zwei PCs/Radmin.
