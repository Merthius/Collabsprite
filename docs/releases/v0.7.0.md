# Collabsprite 0.7.0 Beta — wieder verbinden, gelöschte Inhalte retten

**Eine Datei für Host und Gäste: `Collabsprite.aseprite-extension` unter Assets.** Nicht „Source code (zip)“ installieren. Windows 10/11 x64; Host-Laufzeit und Diagnose enthalten.

## Neu

- **Automatische Wiederverbindung:** Bei kurzem Netzabbruch bis zu zwei Minuten erneut verbinden. Derselbe Bild-Tab, dieselbe Teilnehmeridentität und der noch verfügbare eigene Pixel-Verlauf bleiben erhalten. Zeichnen pausiert währenddessen. Bereits bestätigte Striche werden nicht doppelt angewendet, ausstehende werden nachgeliefert.
- **Gelöschte Ebenen/Frames wiederherstellen:** **Ansicht → Collabsprite → Letzte Löschung wiederherstellen**. Fügt nur gelöschte Inhalte zurück; neuere Zeichnungen in übrigen Cels bleiben erhalten. Für Host und Gäste, letzte gemeinsame Löschung zuerst. Bis 20 Löschaktionen bzw. insgesamt 4.194.304 gelöschte Cel-Pixel, nur solange der Server läuft.
- **Feste Ebenen-/Frame-Kennungen:** Noch ausstehende Pixelaktionen können trotz fremder Löschungen richtig zugeordnet werden. Wurde genau ihre Zielebene/ihr Zielframe gelöscht, stoppt der Abgleich sicher und lässt die lokale Ansicht offen.
- **Host-Zugangsschalter:** „Beitritte erlauben“ ausschalten, um zusätzliche Teilnehmer und Sitzungssuche zu sperren. Bereits verbundene Gäste können weiterarbeiten und kurzzeitig wiederverbinden.

## Weitere Korrekturen seit 0.6.5

- Bestätigte Gastzeichnungen bleiben nach dem Verlassen beim Host; geordnetes Trennen wartet auf die letzten Änderungen.
- Nur der Host speichert/exportiert das Sitzungsbild über die normalen Aseprite-Befehle. **Kein Kopierschutz:** Gäste empfangen Bilddaten; Screenshots, Skripte oder veränderte Erweiterungen können nicht verhindert werden.
- Sichtbare Sicherungsfehler mit Wiederholungsversuch; abgesicherter letzter Backup-Abschluss.
- Letzte Ebene/letztes Frame löschen, Größenlimits oder veraltete reine Strukturaktionen führen zu einem Hinweis statt zum Verbindungsabbruch.
- Begrenzte Warteschlangen/Nachrichtenraten, frühere Validierung und Browser-Abweisung.

## Aktualisieren — auf allen PCs

1. Host speichert die Sitzungskopie, alle trennen ihre Sitzung.
2. **`Collabsprite.aseprite-extension`** herunterladen.
3. **Bearbeiten → Einstellungen → Erweiterungen → Erweiterung hinzufügen**, Datei wählen und Update von **Collabsprite / pixelkollab-native** bestätigen.
4. Aseprite neu starten. **Ansicht → Collabsprite → Info** muss **0.7.0** zeigen.

**Protokoll 4: nicht mit 0.6.x kompatibel.** Alle müssen aktualisieren; neue Sitzung starten. Kein separates Host-, Gast- oder Dev-Paket.

Host: RGB-Bild öffnen → **Ansicht → Collabsprite → Server erstellen / beitreten → Erstellen → Sitzung erstellen** → Einladung kopieren.

Gast: **Beitreten** → Einladung einfügen → Beitreten. Im selben LAN/WLAN direkt; über verschiedene Netzwerke zuerst demselben Radmin-VPN-Netz beitreten.

## Geprüft und verbleibende Grenzen

37 Server-/Netzwerktests, sieben native Aseprite-Batchskripte, zwei native WebSocket-Testabläufe (Struktur sowie absichtlicher Netzabbruch/verlorene Bestätigung/ungesendeter Strich/Undo/Wiederherstellung), Installer-, Hintergrundstart-/Portfreigabe- und Update-Prüfung bestanden. `npm audit --omit=dev` ohne gemeldete Schwachstellen der erfassten npm-Abhängigkeiten.

Wiederaufnahme gilt für eine kurz unterbrochene Verbindung zum **weiterlaufenden** Server, nicht nach Aseprite-/Server-Neustart, absichtlichem Verlassen oder Fristablauf. Keine allgemeine Offline-Zusammenführung. Wiederhergestellte gelöschte Pixel haben nicht ihren früheren Undo-Verlauf; Strg+Z bleibt persönliches Pixel-Undo, kein allgemeines Struktur-/Metadaten-Undo. Nach hartem Host-Absturz kann der Server noch bis zu zwei Minuten warten; reguläres Schließen beendet ihn nach dem Backup.

Beta: Zwei physische PCs, längere Radmin-Praxis, gehaltene Pinselstriche plus gleichzeitiger Strukturumbau und der konkrete Freund-PC-Stack-overflow bleiben offene Prüfungen. Nur vertrauenswürdiges LAN/VPN, keine öffentliche Portfreigabe. Bei Fehlern **Ansicht → Collabsprite → Diagnosekonsole → Protokoll kopieren**.
